# 🏫 Sistem Monitoring Presensi dan Kehadiran Mahasiswa (SiPresensi)

## 📝 Tentang Proyek
[cite_start]**SiPresensi** adalah aplikasi yang dirancang khusus untuk mencatat dan memantau tingkat kehadiran mahasiswa dalam kegiatan perkuliahan[cite: 3, 5]. [cite_start]Aplikasi ini dikembangkan untuk memudahkan dosen atau staf administrasi akademik dalam mengelola presensi harian[cite: 7]. 

[cite_start]Proyek ini dibangun menggunakan bahasa pemrograman **Golang** dan dibuat sebagai syarat untuk menuntaskan Tugas Besar Mata Kuliah Algoritma Pemrograman 2 (AlPro2) di Fakultas Informatika, Telkom University[cite: 1, 2].

## ✨ Fitur Aplikasi
[cite_start]Aplikasi ini beroperasi menggunakan tiga data utama: data mahasiswa, data jadwal kelas, dan data log kehadiran[cite: 6]. Berikut adalah rincian fitur-fitur yang ada di dalam aplikasi:

* [cite_start]**Manajemen Data Mahasiswa:** Pengguna memiliki akses penuh untuk menambahkan, mengubah (edit), dan menghapus data mahasiswa di dalam sistem[cite: 9].
* [cite_start]**Pencatatan Kehadiran:** Sistem memungkinkan pencatatan status kehadiran mahasiswa pada setiap pertemuan dengan opsi status: hadir, izin, sakit, atau alpa[cite: 10].
* [cite_start]**Pencarian Data (Searching):** Pengguna dapat mencari data mahasiswa secara spesifik berdasarkan *status kehadiran* atau *NIM*[cite: 11]. Fitur ini diimplementasikan menggunakan algoritma pencarian:
  * [cite_start]*Sequential Search* [cite: 11]
  * [cite_start]*Binary Search* [cite: 11]
* [cite_start]**Pengurutan Data (Sorting):** Pengguna dapat mengurutkan tampilan data mahasiswa berdasarkan *jumlah total absensi* atau *nama*[cite: 12]. Fitur ini diimplementasikan menggunakan algoritma pengurutan:
  * [cite_start]*Selection Sort* [cite: 12]
  * [cite_start]*Insertion Sort* [cite: 12]
* [cite_start]**Statistik & Laporan:** Sistem secara otomatis dapat menampilkan statistik berupa persentase kehadiran per kelas dan memberikan daftar mahasiswa yang memiliki jumlah alpa terbanyak[cite: 13].
